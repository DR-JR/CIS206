Ryne McCormick Standards for variables and functions in Python. The agreed upon formatting for variables and functions is snake_case: # def this_is_a_function(): # this_is_a_variable = input("Name your variable") It is best to avoid single characters and common words as many are already in use in Python. This is why it is suggested to use descriptive names in snake_case, both to ease readability for the user and also to quickly understand what a function does. Indentation of four spaces or one TAB seems to be the agreed upon spacing in Python, and it helps to align everything so it can be easily understood what the code is doing. The maximum characters on a line of code is suggested to be 79 to make it easier to read with several windows open at once. You can get past this limitation by using the built-in continuation with brackets and parentheses. # groceries = [ # strawberries, oranges, avocados, # bread, bagels, yogurt, # bacon, eggs, milk, # ] Sources: PEP 8 – Style Guide for Python Code.
